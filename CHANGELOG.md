# Changelog

## 0.0.180 — first public release
- Open-source, GLM-native terminal coding agent that drives your own installed ZCode
  runtime / GLM Coding Plan (BYO key). Headless one-shot (`zagent -p`) and interactive TUI.
- Commands: doctor, onboard, models, quota, sessions, diff, memory, cron, plugins.
- Cross-platform runtime discovery (Linux / macOS / Windows); Linux fully validated.
- Ships no upstream binaries; MIT, non-commercial intent. See NOTICE for the
  interoperability disclaimer.
