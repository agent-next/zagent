# Upstream reference clones

The GUI and borrow research compared zagent against local shallow clones of the
upstream repositories below. Re-fetch one with `git clone --depth 1 <url>`.

| clone                | upstream                                        |
| -------------------- | ----------------------------------------------- |
| codex                | https://github.com/openai/codex                 |
| grok-build           | https://github.com/xai-org/grok-build           |
| opencode             | https://github.com/sst/opencode                 |
| zcode-plugins        | https://github.com/zai-org/zcode-plugins        |
| zcode-reverse-engineer | https://github.com/vibe-coding-labs/zcode-reverse-engineer |
| zcode-tui            | https://github.com/xhls008/zcode-tui            |

Line citations in `BORROW.md` and `reference-matrix.json` refer to these clones by
name (`zcode-tui ...`, `grok-build .../...`) at the revisions current when the
research was done; line numbers may have drifted on later upstream commits.
